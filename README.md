# 🚦 AI-Powered Traffic Control System

An AI-powered Smart Traffic Control System that uses Computer Vision and Artificial Intelligence to dynamically manage traffic signals based on real-time vehicle density.

---

## 🏆 Achievement

🥇 **Winner – CSTF 2025 (Coimbatore)**

This project won **1st Place at CSTF 2025** for developing an innovative AI-based intelligent traffic management system.

---

## 📌 Overview

Traditional traffic signals operate on fixed timers regardless of traffic conditions.

This project uses AI to detect vehicles from live camera feeds and automatically adjusts signal timing to improve traffic flow, reduce waiting time, and minimize congestion.

## 🔄 System Workflow

1. User opens the website.
2. Homepage redirects to **login.html**.
3. User logs in.
4. Dashboard displays live traffic monitoring.
5. AI detects vehicles using TensorFlow.js.
6. Traffic density is calculated.
7. Arduino receives traffic data.
8. Signal timing changes automatically.
